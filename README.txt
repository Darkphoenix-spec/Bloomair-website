BLOOMAIR Exports and Logistics — Website
==========================================

This is a single self-contained HTML file: index.html

All images (hero photo, gallery photos, logo, favicon, blog thumbnails)
are embedded directly inside index.html as base64 data, so there are
no separate image files or folders to keep track of — everything you
need is in this one file.

HOW TO USE
----------
1. Double-click index.html to open it in any web browser and preview
   the site locally.
2. To publish it, upload index.html to any web host (e.g. Netlify,
   Vercel, GitHub Pages, cPanel, etc.) — no build step or extra
   configuration is required.
3. To edit content, open index.html in any text/code editor (VS Code,
   Sublime Text, etc.) and search for the relevant text or section
   (Home, Your Roses, Gallery, Airfreight, About Us, Contact Us, Blog).
